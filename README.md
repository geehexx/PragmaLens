# PragmaLens

PragmaLens is a Python evidence and discourse audit engine.

This `main` branch is intentionally minimal and public-safe. Active implementation
work continues on the `development` branch until the runtime, verifier, and
evaluation surfaces are ready for promotion.

## Bootstrap

```bash
uv venv -p python3.12 .venv
source .venv/bin/activate
uv sync
```
